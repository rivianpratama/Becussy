Orange bars are measured in this repo (eval/hongbai_ag1, eval/frontier_bench.py) on one RTX 2060. Blue and yellow bars are Artificial Analysis' published numbers, top-effort variant per model, read from their model dataset on 2026-07-26. The two are not the same harness: AA runs its own prompts, parsing and sampling, and GPQA here uses the ungated fingertap/GPQA-Diamond mirror because the canonical set is gated — same 198 questions, but a fixed option order rather than AA's per-run shuffle. Read the frontier bars as context, not as a like-for-like margin. An em dash means the source never published that number — four models have no IFBench score on AA, and AG1 is ours alone, so no frontier model has a third-party AG1 figure. IFBench is prompt-level strict: an item passes only if every instruction on it is satisfied. GPQA is 4-way multiple choice, so 25% is the chance floor.
